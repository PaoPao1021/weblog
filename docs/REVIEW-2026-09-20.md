# 本地审查与修复记录

审查日期：2026-09-20。基线提交：`23161d5`。

## 已修复

| 优先级 | 问题及影响 | 修复 |
| --- | --- | --- |
| P1 | 终端无条件拦截 Tab 与 Shift+Tab，键盘用户无法按常规方式离开输入框。 | 仅在能够实际补全时拦截 Tab；补全后再次 Tab、空输入、无匹配及 Shift+Tab 保持浏览器默认焦点移动。更新操作提示。 |
| P1 | 命令面板把每次 Tab 都重定向到搜索框，关闭按钮无法通过 Tab 到达；父级 Enter 处理还会覆盖按钮操作。 | 在搜索框与关闭按钮间循环焦点，只在搜索框内按 Enter 时执行选中命令。 |
| P2 | 首次打开懒加载命令面板时，背景已经 inert，组件挂载后记录不到原输入焦点；Esc 关闭后无法返回原处。 | 在打开面板之前记录触发元素；取消和主题操作恢复原焦点，页面跳转后聚焦目标窗口。 |

前三项均在修改前通过浏览器回归用例复现失败，修复后通过。另有目标窗口路由与焦点保持用例，防止恢复旧焦点时切换回原窗口。
